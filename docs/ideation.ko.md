# 바이브 레디 판독기

- 이 프로젝트는 리포지토리의 여러 데이터를 분석해서 바이브 코딩을 할 수 있도록 준비가 되어 있는지를 판독하는 판독기 입니다.
- 인터페이스는 CLI로 제공됩니다.
- 바이브 코딩을 위한 준비가 잘 되었는지는 다음과 같은 요소들을 분석해서 판독합니다.
  - 리포지토리의 구조
  - 테스트 커버리지
  - 문서화 수준
  - CI/CD
  - 훅을 통한 검증
    - lint, ut, it, e2e, 스팩 검증
  - 바이브 코딩을 위한 설정들
    - 규칙 파일
      - CLAUDE.md(or AGENTS.md)
    - 각종 훅
    - 스킬
      - 에이전트

## 개발 프로세스 진단

`--diagnose` 모드는 개발팀의 AI 개발 도입 준비와 개선 효과 확인을 지원합니다. 요구사항·완료 조건, 재현 가능한 개발 환경, 행동·회귀 검증, 검증 피드백, 변경 용이성과 작업 맥락, 추적 가능성, 저장소 유형에 맞는 전달·복구를 평가합니다.

저장소 읽기, GitHub/GitLab PR/MR·CI 기록, 필요한 팀 인터뷰를 근거로 사용합니다. 권고는 관찰된 문제·근거·별도의 원인 가설·최소 개선 작업·완료 조건·효과 확인 방법을 설명합니다. 도구 설치나 설정 개수를 엔지니어링 역량으로 간주하지 않습니다. 근거 부족은 미확인, 적용되지 않는 기준은 해당 없음으로 구분합니다.

서비스·라이브러리·CLI·데이터·일반 저장소 프로필을 지원하고 동일 역량 ID와 관찰 범위로 전후를 비교합니다. PR·CI만으로 실제 배포·장애 성과를 추정하지 않습니다. 상세 내용은 [프로세스 진단 가이드](process-diagnosis.md)를 참고하세요.
